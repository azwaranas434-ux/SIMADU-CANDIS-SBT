# SIMADU-CANDIS-SBT
SIMADU CANDIS SBT adalah Sistem Administrasi Terpadu Satu Pintu Cabang Dinas Pendidikan Menengah dan Khusus Kabupaten Seram Bagian Timur. Aplikasi ini mengintegrasikan pengelolaan data SMA/SMK, GTK, peserta didik, surat-menyurat, kegiatan, SPMB, sarpras, arsip, dan laporan secara rapi, terstruktur, terdokumentasi, dan mudah dipantau.
