Data GTK

✏️ Mode edit aktif — data yang dipilih sedang diubah.
Impor data GTK secara massal dari file Excel (.xlsx/.xls). Kolom yang dikenali otomatis: Nama, Tempat Tanggal Lahir, NIP/NIK, Sekolah, Jabatan, Pengangkatan CPNS, Pengangkatan PNS, Pangkat Terakhir (nama kolom pada baris pertama file Excel).

Data Pegawai Cabang Dinas

✏️ Mode edit aktif — data yang dipilih sedang diubah.
Data kepegawaian staf/pegawai kantor Cabang Dinas Pendidikan Menengah dan Khusus Kabupaten Seram Bagian Timur (bukan GTK sekolah). Impor massal dari Excel (.xlsx/.xls) — kolom yang dikenali otomatis: Nama, Tempat Tanggal Lahir, NIP/NIK, Jabatan, Bidang/Unit Kerja, Pengangkatan CPNS, Pengangkatan PNS, Pangkat Terakhir.

Absen Pegawai Cabang Dinas

✏️ Mode edit aktif — data yang dipilih sedang diubah.
Catat kehadiran harian pegawai kantor Cabang Dinas. Ketik nama pada kolom Nama Pegawai — daftar akan menyarankan nama dari menu Data Pegawai Cabang Dinas. Gunakan tombol cetak per tanggal untuk rekap absensi harian.

Data Peserta Didik

✏️ Mode edit aktif — data yang dipilih sedang diubah.
Impor data peserta didik secara massal dari file Excel (.xlsx/.xls). Kolom yang dikenali otomatis: Nama, Tempat Tanggal Lahir, NISN, NIS, Sekolah, Kelas, Nama Ayah, Nama Ibu, Alamat (nama kolom pada baris pertama file Excel).

Surat & Naskah Dinas

✏️ Mode edit aktif — data yang dipilih sedang diubah.
Isi kolom Isi Surat untuk mencetak surat resmi lengkap dengan kop surat Cabang Dinas — dicetak satu per satu (bukan kolektif) melalui tombol 🖨️ Cetak pada setiap baris data.

Kegiatan & Agenda

✏️ Mode edit aktif — data yang dipilih sedang diubah.
Isi kolom Keterangan/Isi Surat untuk mencetak surat kegiatan lengkap dengan kop surat Cabang Dinas — dicetak satu per satu (bukan kolektif) melalui tombol 🖨️ Cetak pada setiap baris data.

SPMB

🔒 Keamanan & Paten Data

Memuat...

Lindungi data resmi aplikasi (Data SMA/SMK, GTK, Pegawai Cabang Dinas, Siswa, Surat, dll) dengan PIN keamanan. Setelah PIN diaktifkan, aksi Hapus Data, Hapus Semua Data, Restore Backup, dan Muat Ulang Data Awal SMA & SMK wajib memasukkan PIN terlebih dahulu — data tidak bisa hilang atau berubah tanpa sepengetahuan admin.

Backup seluruh data aplikasi ke file JSON. File dapat disimpan sebagai arsip administrasi.

Jika data contoh SMA/SMK (Dapodik) hilang atau kosong — misalnya setelah data direset atau localStorage browser bermasalah — gunakan tombol berikut untuk memuat ulang data awal tanpa mengganggu data lain (GTK, Siswa, Surat, dsb).
